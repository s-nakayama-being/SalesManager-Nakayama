# auto-review 使い方手順書

オープン PR を巡回し、未レビューまたは更新された PR に対して自動でコードレビューをコメント投稿するスキルです。

## 前提条件

- Claude Code がインストール済み
- `gh` CLI がインストール済み & `gh auth login` 認証済み
- このリポジトリを clone してプロジェクトルートで Claude Code を起動

## 使い方

Claude Code を開いて、以下を 1 回打つだけです。

```
/loop 1h /auto-review
```

これで毎時 :13 に `/auto-review` が自動実行されます。Claude Code のセッションを開いている間ずっと動きます。

## 何が起きるか

1 時間ごとに以下を自動実行します:

1. オープン PR を一覧取得
2. 各 PR について「現在の head SHA に対するレビューが既にあるか」を確認
3. 未レビュー or 前回レビュー以降にコードが更新されていれば差分を取得
4. レビューを生成して PR にコメントとして投稿
5. 重複防止のため本文冒頭に `[auto-review for {head_sha}]` のマーカーを付与

## 停止方法

- **Claude Code を閉じる** → 自動で停止します(セッション内のみ動作するため)
- **セッションを閉じずに止めたい場合** → Claude Code に `CronDelete <ジョブID>` と打つ。ジョブ ID は `CronList` で確認できます

## 注意点

- **PC を起動 & Claude Code セッションを維持している間だけ動作します**(クラウド側で動くわけではありません)
- ループは作成から 7 日後に自動失効します。必要であれば再度 `/loop 1h /auto-review` を打ってください
- 間隔を変えたい場合は `1h` を `30m` `2h` などに変更してください

## トラブルシューティング

- **`gh` コマンドの権限プロンプトが出る** → 1 度「Yes, allow always」で承諾すれば次回以降は出ません(`.claude/settings.json` で `gh pr/api/repo` 系は許可済み)
- **PR にレビューが投稿されない** → `gh auth status` で `gh` の認証状態を確認してください
- **Claude Code を起動した直後はループが動かない** → セッション起動後に 1 度だけ `/loop 1h /auto-review` を打つ必要があります(永続化されません)
